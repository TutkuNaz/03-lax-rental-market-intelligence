# Security policy

## Supported version

Security fixes are applied to the current main branch.

## Reporting a vulnerability

Do not disclose a vulnerability in a public issue. Use the repository's private security-advisory form:

https://github.com/TutkuNaz/03-lax-rental-market-intelligence/security/advisories/new

Include the affected parser, file, or workflow, reproduction steps, impact, and any suggested mitigation. Remove credentials, personal information, and proprietary data from the report. Acknowledgement is normally provided within seven days.

Ordinary parser failures, broken source links, and data-quality questions can be reported through GitHub Issues.
